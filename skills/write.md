# 正文生成规范

用于把提纲和场景事实重构成可见、可听、可触的小说正文，也用于在不改动既定结果时做局部润色。`skills/scene.md` 负责场景事实表的构建规范；本文负责视角、人物、对白、情绪和语言。正文不得照抄提纲或场景表。

## 工作顺序

完成 `AGENTS.md` 规定的事实源读取后：

1. 确认本章目标、阻力、人物选择、不可逆结果、固定钩子及相邻章节承接。
2. 为每个场景确定视角人物、当时所知、最怕失去之物，以及进入和离开场景时发生的变化。
3. 选定一组主导画面与感官锚点，明确它们如何随压力升级而改变。
4. 先写人物在明确空间中做事，再让背景、制度和情绪通过行动后果进入正文。
5. 完稿后删除重复结论、说明性旁白、可互换对白和没有改变任何状态的段落。

篇幅由事件、关系和高潮完整落地后自然形成，不为凑字数扩写，也不为统一章长删掉必要因果。

局部修订时：

- 未明确要求改剧情时，保留既定事件、结果、视角、人物边界、章节钩子和场景事实。
- 按成稿检查定位问题，每轮处理三至五处；先修硬逻辑和空间动作，再修信息、人物和表达。
- 沿用下文规则，只作必要的替换、合并和删除；改后连读前后十段。

## 场景转化

- 提纲只规定发生什么。正文必须补出人物如何发现、判断、受阻、选择并承担结果。
- 场景以人物正在执行的动作开场；先建立必要的入口、出口、遮挡、距离、光源和可用物件，再让信息随行动出现。
- 关键动作、动机或物理条件缺失时，补最短的可见桥接；不用“正好”“忽然”“只能”遮掩断点。
- 如有对应 `generated/chapterN_scene.md`，复杂路线、机关、追逐和多人换位须服从其中的事实；正文只选取视角人物当下能够感知且会影响选择的部分。
- 制度通过谁能进门、谁先拿药、账单扣掉多少和谁承担风险显现，不安排角色朗读设定。
- 能力通过范围、误差、消耗、环境干扰和失败代价显现，不集中介绍能力卡。
- 重要物件首次出现应有正常用途；再次出现时改变行动、关系或风险，不能临时生成救命工具。
- 伏笔首次出现须有符合当时信息的普通解释；揭晓后又能沿原有痕迹反推真相。
- 前文的承诺、玩笑、声音或物件可在后文改变含义形成回声，不另起旁白总结主题。

## 视角与画面

- 默认采用贴身第三人称，只写视角人物能感知、记起或据证据推断的内容，不直接宣布他人的真实想法。
- 切换视角必须使用明确分隔，并以新空间、身体状态或正在执行的动作重新入场。
- 新场景先建立视角人物，不连续点名形成角色名单；其他人物通过有效动作、声音或关系进入镜头。
- 每个核心场景使用一组主导意象。光线负责揭示或遮蔽，声音负责逼近、骤停或爆发，环境变化必须影响人物判断。
- 回忆由眼前的声音、气味、伤口或物件触发，只保留会改变当前选择的一至三帧，并立即回到现场。
- 比喻来自人物经历或现场物件；同一段不连续更换互不相关的意象。
- 动作、画面或对白已经表达清楚时立即停止，不再补一句“这意味着”“他终于明白”。

## 人物与对白

- 人物卡不是介绍词。外貌、职业、经历和能力只在现场触发时呈现。
- 人物的欲望、身份、职业习惯、资源处境和底线必须改变其观察顺序、动作选择和说话方式。
- 互换两名人物的动作或台词后若仍自然成立，应重新人物化。
- 对白来自人物当下的需要，不是轮流交代信息。允许打断、迟疑、回避、误解、讨价还价和只回应自己关心的部分。
- 熟人之间不复述双方已经知道的定义、日程和前情。先问“这个人此刻真会这样说吗”，再问信息是否完整；能说“七点去北门，治疗不就赶不上了”，不要写成“七点也是你最后一轮治疗”。
- 人物不必把话说得最理性、最完整。担忧、执拗、慌乱时，允许省略主语、重复、半句、跳接和不精确表达；台词应优先暴露真正的情绪对象。例如父亲担心失联的儿子时，应让话重新落到儿子身上，而不是冷静分析去哪里能问到消息。
- 不为“有生活感”强行安排抬杠。玩笑、反问和顶嘴必须来自既有关系与当下情绪；若会把人物注意力从真正关心的事上移开，就删掉。
- 连续检查三轮对白：若每一句都准确回答上一句、每个人都完整给出条件—分析—结论，主动打散这种“说明书式”结构，让人物只说现场真正需要说的部分。
- 除紧急命令外，对白应同时承担态度、事实依据、隐含目的或关系变化中的至少两项。
- 身份决定说话和行动权限。下位者报告事实、试探或建议；未经授权不能替上级指挥、裁决或分配资源。
- 高智人物不完整讲解计划，只给必要指令、有限证据或半层结论，让后续行动证明其判断。
- 情绪落在人物特有的动作、物件和未完成的话上，不使用通用手抖、攥拳或抽象情绪词替代人物反应。
- 生活细节必须带出关系、资源或习惯；不能只在人物死亡前临时补一段经历。
- 伤亡应回收人物既有承诺、习惯、伤口或随身物件，不用人数统计替代失去的体感。

## 冲突与高潮

- 智斗必须具备信息来源、准备成本、执行窗口、失败后果和对手复核；胜利不能依靠临时能力、临时道具或对手失常。
- 包扎、争执、观察和开锁需要可见的时间窗口，并持续用断裂声、逼近动作或光线变化提示窗口正在关闭。
- 每次暂时脱险都应留下伤势、消耗、暴露、路线损失或关系裂痕，压力不能无代价归零。
- 高潮只聚焦少数情感主线。其余人物仍须行动合理，但不平均分配临终特写。
- 高潮按“蓄压—收镜—爆发—刺点”推进：先建立逐渐逼近的信号，再收紧到身体或关键物件，让动作、感官变化和人物选择同时爆发，最后停在一个最锋利的画面或句子。
- 揭密、追杀或重大选择开始后持续收紧，不插入无关笑料、机制教学、战果统计或复盘。
- 固定钩子必须成为章节最后一个有效信息或画面；解释和下一步方案后移到下一章。

## 本项目基调

- 末世压力不仅来自怪物，也来自资源如何分配、危险由谁承担、谁有权决定他人的价值。
- 残酷制度必须解决过真实问题，理想制度也必须支付资源、效率和牺牲的代价。
- 希望来自人物看清代价后仍选择共同承担，不来自突然出现且免除代价的救世力量。

## 转化示例

- 提纲写“她意识到被骗”，正文应给出她能核验的矛盾证据、停住的动作、改变的称呼或新的选择。
- 安全感转为危险时，使用已经入镜的物件反证；完整粮食先带来希望，随后由没有鼠咬、翻找和搬运痕迹暴露异常。
- 高潮中人物刚看见生路时，不先解释威胁追到身后；让身体触感、突然进入视野的伤口或中断的动作直接完成反转。

## 成稿检查

1. 因果：目标、阻力、选择、结果和钩子闭合；胜负来自准备、信息和代价。
2. 连续性：时间、距离、站位、朝向、视线、路径、受力、耗时、双手、光源、伤势、能力、人数和物件一致；动作不重复，消耗不凭空恢复。
3. 人物：行为符合人物卡；对白具有身份差、个人词汇、潜台词和关系变化。
4. 行文：核心场景可见可听；没有旁白代读、百科说明、重复情绪或高潮泄压。
