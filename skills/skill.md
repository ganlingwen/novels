# Skill 编写规范

编写或修改 `skills/` 下的规则时，满足以下要求：

- 无歧义
  - 一条规则只表达一个判断。
  - 明确对象、条件和结果。

- 可执行
  - 使用可检查的文本、事实或动作。
  - 能直接判断通过或违反。

- 简洁
  - 使用短句。
  - 一个句子只表达一个判断。
  - 多个判断拆成 bullet points。
  - 删除不影响判断的解释、重复和修饰。

- 具体
  - 使用可观察的条件。
  - 不用无法直接核对的抽象词作为判据。

- 通用
  - 不依赖特定章节、人物、句子或一次修改记录。
  - 更换文本后仍可直接执行。

提交前逐条检查。
任一项不满足，先修改规则。
