# 灰雾行者

以本仓库小说为背景的 Godot 4.5 单机俯视角 RPG 原型。设计与后续阶段见 [PLAN.md](PLAN.md)。

当前版本已将机制原型改为画面优先的可玩样板：全屏街区、人物与敌人动画、图标技能栏、场景内出发入口，以及按需打开的成长面板。后续开发或重写先读取 [协作规范](AGENTS.md) 与计划中的 VIS / UX 规格。

## 启动

本机已准备好 Godot 4.5.1。双击 `run.command`，或在仓库根目录运行：

```bash
./game/run.command
```

也可用 Godot 打开 `project.godot`，按 F5 运行。在其他机器上需先安装 [Godot 4.5 或更新的 Godot 4](https://godotengine.org/download/)；本项目尚未导出独立安装包。

第一次试玩：点击右上角模式按钮切到**自动探索**，再点击角色旁的**出发探索**。角色会自动清怪、取核、打 Boss 并返程；左上角“角色·背包”可打开成长面板。

## 已实现

- 手动、辅助、自动三模式，共享移动、攻击、技能、碰撞和资源判定。
- 一张含建筑障碍的街区地图；可辨认的玩家、3 种普通尸、枝印精英和 Boss，具有移动、攻击、受击、倒地及取核表现。
- 倒地与取核分开结算；Boss 范围冲击预警；自动绕障、避险、喝药与回城。
- 角色 1～10 级；四项属性，每级 3 属性点、1 天赋点；基地免费洗点与推荐加点。
- 12 个天赋节点，含前置及互斥分支；4 个雷系主动技能。
- 六个装备槽、15 个装备模板、4 档品质；遗物掉落、拾取、换装与丢弃。
- 任务交付、重复出发、暂停、死亡救援和本地存档。

当前是视觉与机制样板：一轮全自动行动约 40 秒，尚未扩展为计划中的 20～30 分钟内容。暂无音效；尚未做剧情、制作、随机词条、能力突破、永久崩坏或感染。枪械暂不管理弹药。晶核只记录本次待上缴数量，不兑换经验或自由交易。

## 操作

| 输入 | 功能 |
| --- | --- |
| WASD / 方向键 | 移动；自动模式下立即接管，停止输入 1.2 秒后恢复自动 |
| 鼠标左键 | 在射程内攻击靠近鼠标的敌人，可按住 |
| 1 / 2 / 3 / 4 | 雷击 / 连锁电弧 / 震雷 / 蓄能护盾 |
| 空格 | 闪避，消耗体力，短暂无敌 |
| Q | 使用急救药品 |
| Tab | 手动 → 辅助 → 自动 |
| E | 基地出发；在入口交付或撤回 |
| Esc | 暂停 / 继续 |

辅助模式自动攻击与施法，玩家移动；自动模式额外处理寻路、取核、避险及返程。靠近倒地丧尸自动取核。攻击与技能不能穿墙。

属性、天赋和换装在基地调整。普通攻击不增加负荷；技能积累短期负荷，达到上限前停止施放，负荷随时间消退。暂停冻结战场。

## 存档

成长、背包、装备与委托完成次数自动保存；也可点击“保存进度”。macOS 默认位置：

```text
~/Library/Application Support/Godot/app_userdata/灰雾行者/survivor.json
```

中途退出后从基地继续，当前敌人、地面遗物、取核任务进度不保留。失败不扣成长；出发时免费补满生命和 5 份药品。这是便于试玩的原型规则。

使用临时文件写入后替换存档；无效存档保留 `.invalid-时间戳` 备份。测试使用 `/tmp` 独立存档，不覆盖玩家进度。

## 开发与验证

```bash
# 成长、战斗、存档，以及三组新角色全自动通关
./game/run.command --headless --script res://tests/run.gd

# 真实窗口、快捷键与界面操作；截图写入 /tmp
./game/run.command --script res://tests/ui.gd

# 在编辑器继续开发
./game/run.command --editor
```

已在 macOS / Godot 4.5.1 验证：33 项规则及完整行动检查、16 项界面检查通过；基地、战斗、Boss 预警、属性、天赋和装备画面已人工检查。新版仍等待首次试玩者确认是否足够直观；尚未验证 Windows/Linux 和独立导出包。

| 文件 | 职责 |
| --- | --- |
| `scripts/rules.gd` | 属性、经验、技能数据、天赋、装备及角色序列化 |
| `scripts/world.gd` | 战场状态、二维寻路、碰撞、手动/自动战斗、任务 |
| `scripts/main.gd` | 绘制、界面、输入、保存触发 |
| `scripts/presentation.gd` | 全屏街区、角色动画、精简 HUD 与成长弹窗 |
| `scripts/save_store.gd` | 文件存储、版本及损坏存档处理 |
| `tests/` | 行为与界面验证 |

后续 3D 可复用成长规则和数据；空间、寻路、命中、摄像机与美术需要相应改造。
