## 1. 成片目标与改编取舍

制作约 2–3 分钟的精简叙事短片，采用写实悬疑风格。观众需要看懂：小文发现异常，但救命的物资让大家继续冒险；有人用物资和机关设伏；队员曾相互救助，最终只有小文逃出；新的追猎已经开始。

下面 40 个剪辑镜头的目标时长合计 145 秒，包含一次 3 秒黑场。片名、片尾另预留 4–8 秒。时长是剪辑目标，不能把 40 个约两秒的生成片段直接宣称为两分半成片。需要长于素材的镜头，应生成较长素材或使用明确规划的静帧停留；不靠整片慢放凑时长。

保留六人同行、新泥与新漆、完整粮油、止轮片和鱼线、西门焊死、双开服务门、两道不同用途的货架、暗扣、阿慧的包扎、沈蓉的冰糖、老秦断后、周勇松手、阿慧救小文、独自逃生和凶猫尾随。家庭治疗账目不在这版展开，留给后续长版；用一次画外对白交代物资与救人的关系。不会提前揭露幕后设伏者，也不引入第一章没有的丧尸追逐。

情绪节奏：S01–S10 让观众观察并产生希望；S11–S21 揭露陷阱；S22–S34 交叉剪辑救人与清障，直到崩溃；S35–S40 重新放慢，留下猫追人的威胁。

音频仍然延期。下文的对白与声音只作为后期剪辑标记；第一版用少量字幕替代必要对白，不运行配音模型。字幕、招牌文字、巨熊标记、血线等精确元素允许后期合成。

### 空间规则

具体尺寸见场景事实表。剪辑必须让观众依次认识四个区域：街巷 → 后仓 → 冷库走廊 → 东后巷。

- 南侧顾客门被犬群截断；西侧安全门焊死；队伍从后仓东侧双开服务门进入走廊。
- 走廊从西向东：入口 → 斜架 R1 → 可移动高架 R2 → 南侧冷库门 → 南侧维修凹位 → 尽头隐藏员工门。
- R1 是卡住野猪的斜架；R2 是后来两人横推挡猪的带轮架。不能合并成一架。
- 走廊侧向镜头暂定向东逃生为画面左→右；摄影机在轴线同一侧。沿走廊看出口的正向镜头可作重新定位镜头；不随意镜像来修运动方向，以免右腿伤变左腿伤。
- 野猪先从冷库冲出向西，卡在 R1；脱困后向东撞 R2、追周勇；门回弹后转身向西，阿慧此时才推小文入凹位。
- 全队六人；五人进入走廊，老秦留在后仓；最后独自走入雨巷的是小文。

### 曝光与美术

室外是灰雾白昼，不是黑夜；室内断电，手电和门缝天光是画面内的光源，以柔和反射光保留人脸和空间细节。后仓暗处也要能区分货架、粮袋和人，不拍纯黑剪影。

保留蓝灰天光、褐色锈迹、米袋米白、油液金黄、肤色和衣服色差。不堆叠“鲜艳霓虹、漆黑、强烈逆光、极高对比”等相互冲突的指令。“HDR”字样不等于实际 HDR 编码，本片先按普通 SDR 成片控制曝光。

## 3. 逐镜分镜与 prompt

使用方式：每条实际 prompt = 下方统一风格前缀 + 对应镜头的「画面提示词」。提示词里的景别和动作属于生成内容；时长、字幕、转场与画外声音由剪辑控制，不一并要求模型完成。

统一风格前缀：

> 写实真人悬疑电影，灾变后的中国城市，真实人物和物体比例，自然皮肤与旧物纹理。灰雾白昼，室内由手电和入口天光的柔和反射照明，主体正常曝光，阴影有细节，面部可辨，自然克制的色彩。单一连续镜头。

表中时间为目标成片时长。通常一个镜头只包含一个主动作；人物受击、货架倒塌等不可靠的接触动作优先用相邻镜头的剪辑表达。

### 镜头替代方案

这些替代保持同一个剧情结果，不靠无限增加 steps 硬救错误画面。

- S02 人数不稳定：使用核对过的六人静帧缓慢平移，再接 S04/S05 单人镜头。明确是静帧运动，不算人物动作生成成功。
- S06 标记、S11 鱼线、S12 裂纹、S18 空间和 S40 双血线：必要时采用分层静帧与后期合成；准确传递信息优先。文字与图案不以模型生成结果为准。
- S14 三犬融合：拆成一只出门、后两只在笼口的短插入镜头；三只总数由剪辑说明，不额外增加犬。
- S19/S21 野猪变形：先固定体型与骨刺位置的参考造型；首轮只考核出门和卡架，不同时要求撞人。
- S24 推架关系错误：拍“两人手握架柱”与“架子已横断走廊”两张连续状态，剪辑连接。
- S26 不要求展示 R1 脱销到猪冲撞 R2 的全动作。用地销脱落的插入静帧、角色反应、第二架受压来衔接；不能让猪同时卡在两架上。
- S30–S32 接触动作失真：门前奔跑、切黑/晃动反应、踏步上的静止土黄身影、门回弹、糖落地分开完成。保留周勇先死、沈蓉随后遇害的顺序。
- S33 双人互动失败：青年已经位于凹位内，阿慧双手推肩的近景静帧，接 S34。不能剪成阿慧也安全进入。
- S37 复杂下台阶失败：拆为扶门框的手、右腿落上一级踏步、门外单人远景，五级台阶由环境静帧建立。

## 4. 可执行的分阶段计划

### A. 先确认视觉和因果，不进行全量生成

先做 S03、S04、S08、S18、S21、S33、S39 七个关键画面，涵盖物证、人物、曝光、空间、野兽和双人互动。它们是能力探针，不作为最终质量承诺。

试拍参数可用 `640×368 / 17帧 / 12steps`。这是低成本构图与动作试验，不是官方质量基准；低步数失败不能直接说明最终设置也失败。只有 1.06 秒的素材不足以判断长动作。

只执行获准后的单个样本，串行运行。最先看 S04：若人脸仍像鬼影或曝光错误，先核对模型、文本编码器、采样配置及解码流程，再调提示词；不通过不断加“高清、真实”掩盖管线问题。

### B. 技术准备与资源检查（未来执行前）

- 当前脚本通过本地 ComfyUI 运行 T2V；浏览器不需要开启。模型、配置、输出位置以 `media/README.md` 和脚本实际值为准。
- 现有 shell 只有 prompt、宽高、帧数、steps 参数。seed 当前固定为 42；负面提示词和文件名前缀也固定。多次完全相同参数并不是多个独立候选。需先加 seed 和逐镜输出标识，或由人工记录参数到输出文件的映射，再做系统性选片。
- 当前负面提示词含 `extra people`，群像可能受影响；未来需允许逐镜指定负面词。优先抑制模糊、解剖错误与字幕水印，避免用会排斥正常群像的词处理所有镜头。
- 每条素材记录镜头号、完整 prompt、负面词、seed、模型名称、采样器、scheduler、CFG、分辨率、帧数、steps、输出路径、耗时与内存峰值。固定 seed 仅用于相同设置下的可比测试，不保证跨镜身份。
- 正式试验前核对现用工作流与对应 Wan 模型的采样配置，包括 timestep/flow shift；本方案不预设“默认工作流已经最佳”。
- 读取训练进程、系统可用内存、GPU/共享内存、swap 和压力指标。若设备是统一内存架构，CPU offload 仍消耗同一物理内存池，不能把 CPU 内存和 GPU 内存当作互不影响的预算。
- 现有脚本新建 worker 时设 24 GiB `MemoryMax` 和 4 GiB `MemorySwapMax`，但复用 8188 已有服务时会跳过启动前内存检查，也不自动给已有服务加限制。执行前要确认实际 worker 的限制和负载。
- cgroup 限制不能保证绝不系统 OOM；需为训练峰值和系统保留余量。先用单样本测峰值，再决定是否延长；只靠一次 `MemAvailable` 或降 steps 无法证明安全。发现训练异常、持续 swap 或明显内存压力就停视频任务，不杀训练任务。

以上是后续实现/核查清单，本次不更改运行脚本，不下载模型，不暂停训练。

### C. 建立可信样片与静音粗剪

在小样可用后，先把 S04、S21、S33 三个风险镜头用 `832×480 / 33帧 / 30steps` 复测。只在测得内存余量后运行；不把这些参数称为已验证的最佳画质。构图通过后优先解决脸、曝光、肢体与运动方向，再扩大到全部镜头。

先用静帧和获选短片拼出 145 秒粗剪。需要字幕的主要信息：新车异常、“六个进去六个回来”、粮食给病孩、别碰车、西门焊死、暗扣在右下、别松手。先看不用解释能否理解因果，再精做每条动态素材。

没有为所有 39 条生成镜头预先承诺一次成功。每个失败镜头先辨别构图错误、动作错误、身份漂移或空间错误；改一个因素复试，连续两个候选仍有同类结构问题就采用替代分镜或静帧方案。

### D. 按镜头时长生成与精剪

当前输出为 16 fps：33帧约 2.06秒、49帧约 3.06秒、65帧约 4.06秒、81帧约 5.06秒。这是播放时长换算，不是安全内存保证。长镜素材宜留剪辑余量；65/81帧需要单独验证内存，不能直接在训练旁边批量运行。

- 2秒动作插入镜头：优先33帧素材。
- 3秒镜头：先试49帧；若资源不够，拆成两个短镜或静帧停留。
- 4–5秒环境/观察镜头：可用已核对静帧的小幅平移、短片加合理停留；需要持续真实动作时再申请相应长度素材。
- 多人搏斗只取动作方向明确的片段，不用光流插帧掩盖手脚融合和人物凭空出现。
- 一致曝光与颜色，雨声和金属声留待后期；音频仍按用户要求延期。

初版素材需求为39个生成/静帧镜头加1个黑场，替代插入镜头可能增加数量。运行预算先用三条实测样本估算：各类镜头的耗时 × 数量 × 实测返工系数，再加剪辑工时；不在训练争用情况下猜一个小时数。

## 5. 逐镜验收与交付

每条只记录“通过 / 需重做 / 改用静帧”，并记录原因：

1. 看得清：脸、手、出口与关键物证正常曝光；小尺寸播放仍能理解主动作。
2. 人物对：同一人物衣服与体态一致；没有突然多出人物；小文伤在右侧，伤势按事件累积。
3. 空间对：门与架子不变位；R1/R2 不混淆；逃生和野猪运动方向可追踪。
4. 因果对：先装货后触发；先开门后周勇松手；猪回身后阿慧推人；猫在结尾追踪。
5. 情绪对：沈蓉先关心孩子再落糖；老秦数人后失去回应；阿慧先包扎后救人；结尾没有把凶猫拍成温情陪伴。

计划交付：逐镜参数与文件映射、候选素材、145秒左右静音粗剪、修改记录、最终画面版。素材建议归档至 `generated/videos/chapter1/`，文档保存在 `media/`；当前脚本尚不会自动按这个目录结构输出。

第一阶段完成标准不是“命令成功写出 WEBM”，而是七个关键画面足以确认这套画面风格可用、空间能表达，并明确需要升级工作流的镜头。若纯 T2V 无法保持小文和阿慧身份，再决定是否投入参考图与图生视频，不先批量消耗训练资源。
