# 第四章场景事实

![第四章西墙涵管空间结构](chapter4_scene.svg)

## 空间

- 住处沿用第三章布局。父母床在帘内；窄褥、矮桌、木凳、花盆、水盆和窗板在帘外。
- 窗板开启时，斜雨可打湿矮桌、木凳和地面。水盆挡在窗前。
- 西墙南北延伸。西北侧为西环高架和化工仓；墙内为菜地、育苗架和清理区。
- `V`：墙内菜地。小文清除豆秧；老杜修育苗架。
- `U`：墙下灌溉涵管，口径约一点二米。墙内出口装铁栅 `G`。
- `G`：栅条未断；基座离土，外缘裂缝约两指宽。
- `R`：涵管旁已有老根。根须可缠住 `G` 的基座。
- `C`：独轮车。翻倒后可遮住小文双手；老杜仍能看见根须。
- 木楔从 `G` 内侧斜入实土，与 `R` 共同承重。
- 涵管边缘有锈蚀钢筋。持续挤压会使其向墙内弹出。
- 西墙是基地最外层防线，南北延伸；墙内菜地贴着西墙布置。
- `U`：旧灌溉涵管直接穿过西墙，墙内出口装铁栅 `G`。
- `D`：西墙正门，位于涵管以南，是人员与车辆正常出入西区的通道；警报后由守卫封控。
- `I`：内墙，位于西墙后方，把体育馆核心区与西墙前沿作业区隔开。清理组接令后从西墙前沿撤过内墙。
- `T`：体育馆地下入口，位于内墙之后，是警报时居民继续下撤的入口；人群撤离方向为西墙前沿 → 内墙 → 体育馆地下入口。
- 方岳分盾组到三处：涵管 `U`、正门 `D`、内墙转角 `M`。这三处不是同一条墙上的三个洞口。
- `M`：内墙靠近西墙通道的一处转角。尸群退去后，老杜沿墙内通道从涵管处送到这里；救治线设在此，白川、药箱和伤员在此。
- 裁决大厅：马克居高处；小文在中央；白川、天干和罗炽分坐两侧；老杜在后方担架上。

## 初始状态

- 小文未登记；能力逼近1级。发动范围近，且必须有活植物。
- 小文右腿不能完全承重；右肋、后脑、右肩和双手未愈。
- 前夜反噬：右手强直、重影、耳鸣、鼻血、右臂痉挛。清晨无名指仍迟滞。
- 共同记录只含轻症；私密记录藏在褥子内。
- 家庭账户此前为15点。小文领取3点墙内轻工。
- 老杜：61岁，独腿木匠。断腿残端有感染史。
- 老杜备有废床腿木楔，能判断入楔位置和角度。
- 外来搜索队点燃化工仓。约二百一十只低阶丧尸转向西墙，误差约二十。
- 主群约一千七百只，继续沿高架东移。支流无二级撞城个体。
- 封衢停在高架，不参加冲击。林夏只能确认远处固定震动。
- 罗炽手臂烧伤，原排在老杜之前治疗。

## 总调度

| 阶段 | 小文与老杜 | 西墙、尸群与基地 | 连续结果 |
| --- | --- | --- | --- |
| 第三夜 | 小文清理鼻血，藏起右手和私密记录。 | 母亲发现右手异常，要求查看全部记录。 | 小文继续隐瞒。 |
| 次日清晨 | 小文只交共同记录，领取墙内轻工。 | 母亲要求其避开泥土并找白川复查。 | 小文带伤到 `V`。 |
| 正午警报 | 小文在 `V`；燃油味和铁门声触发旧事记忆。 | 尸群支流转向西墙；清理组撤离。 | 旧事发生在近身加固前。 |
| 首轮撞墙 | 小文发现 `G` 基座失效并报告。 | 丧尸挤压 `G`；墙头无人可调。 | 守卫吹哨求援。 |
| 涵管加固 | 小文翻倒 `C`，催动 `R`。老杜指挥入楔并遮挡根须。 | 根须与木楔共同承重。 | `G` 暂停倾斜；能力未暴露。 |
| 钢筋弹出 | 小文维持 `R`，右手蜷紧。老杜将其撞开。 | 钢筋贯穿老杜断腿残端。 | 小文用衣摆、木楔、根须和生命力止血；老杜继续遮挡。 |
| 封衢退兵 | 小文持续压迫伤口，随担架到 `M`。 | 沙袋补住 `G`；封衢召回尸群，向马克张开五指。 | 小文怀疑双方有默契；不知道手势含义。 |
| 救治线 | 小文托腿并递垫布。 | 方岳隔开罗炽；天干批准白川优先救治老杜。 | 动脉止血；深层污染；抗生素窗口约四十八小时。 |
| 当日晚间 | 小文对老杜施术，只能减慢坏死。 | 父亲记录；母亲叫停；老杜交出木工凿并教授夹层。 | 感染未解除；小文反噬加重。 |
| 再下一日 | 小文进入裁决大厅。 | 四份公开记录均缺失根须介入。 | 马克追问老杜存活原因。 |

## 结束状态

- 西墙守住。`G` 由木楔、沙袋和根须固定。
- 封衢退向无人区；已确认涵管位置。五指含义未公开。
- 老杜动脉出血暂止；深层感染进入四十八小时窗口。
- 罗炽仍需治疗；白川改变顺序；天干承担授权责任。
- 小文能力未公开；反噬未恢复。
- 父母已发现部分异常，尚未看见私密记录。
- 小文持有木工凿，并学会制作木拐夹层。
- 第五章开篇直接承接马克的提问。
