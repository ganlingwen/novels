# 第四章场景事实

![第四章西墙涵管空间结构](chapter4_scene.svg)

## 空间

- 住处沿用第三章布局。父母床在帘内；窄褥、矮桌、木凳、花盆、水盆和窗板在帘外。
- 开篇母亲已在窗前小文身后；父亲整夜留在帘内。母亲将小文扶回窄褥并拖凳守候；清晨小文将花盆挪回窗下，把木凳放回原处。
- 西墙南北延伸；墙内前沿由北向南分布菜地、涵管、西墙正门。
- `V`：墙内菜地。小文清除豆秧；老杜修育苗架。
- `U`：旧灌溉涵管，穿过西墙，口径约一点二米；墙内出口装厚木闸门 `G`。
- `G`：门后两侧留有横木槽，备用横木搁在门旁。横木两端入槽，木楔塞紧余隙。
- `R`：涵管附近地下有活根，小文可催动。
- `D`：西墙正门，位于涵管以南。
- 正门内侧有登墙石阶。马克由此登墙，停在正门上方的外侧垛口；面向高架及墙外尸群，不到涵管上方。
- 小文与老杜在涵管墙内出口的木门后。西墙及门体隔开墙外观察线；马克所在的正门弩位不能直接看到两人在门后贴地施术的双手。
- `I`：内墙，位于西墙后方；设出入口 `M`。
- `T`：体育馆地下入口，位于内墙之后。
- 撤离方向：西墙前沿 → `M` → `T`。
- 救治线设在 `M` 后。
- 木闸遮挡小文的城外视线；他只能感知门缝、退去的嘶吼、墙头喊声及映入墙内的火光。封衢手势由西墙上的马克视角呈现。

## 初始状态

- 小文未登记；能力逼近1级，发动范围近，必须借活植物。
- 小文右腿不能完全承重；右肋、后脑、右肩和双手未愈；右手仍有强直反噬。
- 老杜：61岁，独腿木匠；此前在菜地修育苗架，与小文一同撤离但速度较慢。
- 老杜参与修过涵管木闸，知道门后的横木加固方式。
- 外来搜索队点燃化工仓。约二百一十只低阶丧尸转向西墙。
- 主群约一千七百只，继续沿高架东移。
- 封衢停在高架，不参加冲击。
- 罗炽手臂烧伤，原排在老杜之前治疗。

## 总调度

| 阶段 | 小文与老杜 | 西墙、尸群与基地 | 连续结果 |
| --- | --- | --- | --- |
| 第三夜 | 母亲守到小文手指松开；小文仍将鼻血归为撞伤，没有交出私密记录。 | 父亲在帘内醒着询问。 | 清晨小文把花盆和木凳放回原处；公开记录只写轻微头痛。 |
| 次日清晨至正午 | 父母追问记录，小文因口粮缺口去 `V` 做轻工，答应手再麻即找白川、晚上补全记录。老杜让出空箱供他坐，分给他解旧绳的活。 | 母亲当天的治疗仍未凑足贡献点。 | 小文右手仍有迟滞；两人均行动不便。 |
| 正午警报 | 老杜把工具和修育苗架剩下的木楔收进腰袋；两人随清理组撤向 `M`。 | 约二百一十只丧尸转向西墙。 | 小文、老杜落在撤离人群后段。 |
| 五分钟广播 | 小文得知涵管只能再撑五分钟，折返 `U`。老杜因放心不下跟回；以自己修过木闸、知道加固方法说服小文让他同行。 | 墙头继续防守；涵管下方人员已撤。 | 两人一起到 `U`。 |
| 木闸与根网加固 | 小文将横木左端入槽，老杜削短右端；两人抬右端时被鼓起的门板挡住。小文催动活根兜回门板，再与老杜将右端入槽。老杜发现根网但不揭穿，用木楔塞紧两端；小文退到老杜身前。 | 原门闩濒临断裂，尸群持续撞门；根网两端扎入门旁土层。 | 横木与根网共同承压；老杜腰袋尚有一块木楔。 |
| 墙上对峙 | 小文未看见墙上的手势。 | 横木与根网暂时稳住木闸时，马克经正门石阶登墙，停在正门上方迎向高架。封衢以五指示意；马克放出金焰，弩手转向高架。 | 对峙尚未结束，撞城与硬肩尸开始冲击涵管。 |
| 老杜受伤 | 横木达到极限后劈裂，形成向墙内斜下方折出的尖锐断木。小文仍在近处维持根网，未能及时避开；老杜将他拖离，自己倒地，断木刺入断腿残端。 | 原门闩仍在；木闸没有完全打开。 | 横木加固失效，老杜受伤，只剩门闩与根网继续承压。 |
| 最后苦撑 | 小文不能去救老杜，只能继续维持根网。木闸与门闩继续变形，局部裂缝扩大到足以伸入丧尸手臂，但不足以让身体通过。根须开始逐根崩断，小文反噬加重。 | 尸群持续挤压木闸。 | 再承受少数撞击即会彻底失守。 |
| 封衢退兵 | 撞击停止，门缝内的手退去；小文随后看见南侧墙头火光，听见有人呼喊马克。 | 封衢收回手势，以嘶鸣召回涵管外尸群，随后退入灰雾。 | 木闸仍关闭；退兵后小文才松开根网救老杜。 |
| 墙下止血至救治线 | 小文用衣摆包住外露木茬周围、剩余木楔隔布加压，并暗中导引门旁活根生命力减缓出血。白川到场固定木茬；老杜被抬上担架时，小文松开枯根，继续压住布和木楔，随担架到 `M`。 | 白川要求进救治线后再取木茬。 | 断木原位保留至救治线；根须介入未写入公开记录。 |
| 救治 | 小文协助白川。 | 天干批准优先救治老杜。 | 动脉止血；深层污染；抗生素窗口约四十八小时。 |
| 当日晚间 | 小文在医务区与父母会合，替卧床老杜关窗。父母在场监督施术；第四息后小文出现耳鸣、重影和右臂抽动，母亲将他的手抬离伤处。老杜交出木工凿，指明小文短拐的开槽位置，不让他当晚动凿。 | — | 感染只被拖慢；小文因反噬脱口阻止母亲，随即意识到失控。 |
| 当晚回住处 | 回到住处已过熄灯时分。母亲暂缓追问记录，让小文先洗手。小文趁母亲去倒水，把褥子下的纸板又往里推了推，听到帘内父亲咳嗽后停手。 | — | 私密记录仍未交出，延续到第五章裁决后。 |
| 再下一日 | 小文进入裁决大厅；老杜留在医务区。 | 公开记录缺失根须介入。 | 马克追问老杜存活原因。 |

## 结束状态

- 西墙守住；涵管木闸受损，横木已断。
- 封衢退向无人区；五指含义未公开。
- 老杜因救小文受伤；动脉出血暂止，深层感染进入四十八小时窗口。
- 小文能力未公开；反噬未恢复。
- 小文持有木工凿，并学会制作木拐夹层。
- 第五章开篇直接承接马克的提问。
