# 第十章 暴雨仓库

![第十章主画面：火、水与碎裂的影子](chapter10_keyframe.jpg)

父母的名字落在纸上，像两道已经执行了一半的判决。

雷声滚远以后，登记室重新暗下去，只剩门外油灯从缝隙里漏进一线橙光。

小文没有时间愤怒。他先核对父亲的床位号、肾衰记录和三次治疗结果，再看母亲领取半份配给的日期、左侧失能评估与分拣效率。全部相符，不是重名。

他的名字没有固定转运编号。“家属反抗时，一并处理”不是提前选中他，而是给执行者留下授权：父母顺从，他仍是可以挣贡献点的劳动力；只要阻拦，地支便能当场把他补进人数。

西侧有人喊：“第五列搬空了！去看登记室有没有进水！”

脚轮碾过货架间的地砖，正在转向北廊。

小文从袖口抽出细根，沿门槛下方送入裂缝，让末端抵住贯穿货架区的铁排水槽。每一道接缝的震动都顺着金属传回指腹。

他继续核对日期、人数、车牌暗号和经手签名，最后看向页脚。红色印泥向内缺了一角，与马克在裁决大厅签署药房移交令时使用的私人印章完全一致。

脚轮越过第四列。

三息之后，小文撕下能形成证据链的四页纸，用油布卷紧，塞进老杜木拐的夹层。

账册主体仍留在手里。

这是他准备让追兵夺回去的东西。

钥匙插进登记室门锁，只转了半圈。

“西排又塌了一层！排水泵堵死了！”

门外的人骂了一声，抽走钥匙，踩着积水向药品区跑去。小文制造的故障替他争到了最后十几息，也让所有还能调动的人都聚向西侧。

门外雨声忽然变得更清楚。

登记室位于仓库北侧夹层，正门向南连接低矮货架区，东墙高窗外就是装卸巷；西侧药品区地势最低，堵住的排水口已经把半座仓库的雨水压在铁闸后。小文原计划从东窗出去，再隔着整片仓库拉开西闸。

这条路线没有真正的安全出口，每一段只负责破坏地支的一种优势。

仓库里的油灯同时熄灭。

黑暗从货架之间合拢。小文没有听见脚步，地支的声音却从四面传来。

“看完了吗？”

第一道影刃贴着登记室门框切下，将木门和退路一同斩断。

小文撞开侧窗，冲向最深处的药品区。那里没有第二个出口，也不可能藏着接应者。地支没有立刻杀他，只用一道道影刃逼迫他改变方向。

“账页少了四张，账册却还在你手里。”地支的声音从左侧货架后移到右侧，“留下整本作诱饵，撕走的才是要交给别人的东西。拿给谁？”

“真有人接应，我不会一个人进来。”小文贴着货架后退，“你已经看过门外影迹，何必再问？”

“现在没有，不代表出去以后没有。你会去见人。”

小文喘了一口气，肩背贴上冰冷铁皮：“那就跟紧点。雨这么大，走丢了别算在我头上。”

小文踢翻第一盏预藏油灯。火焰沿地面铺开，将货架阴影推远半步。地支从墙面暗处退出，轮廓只出现一瞬，影刃已经割开小文肩背。

双方差距没有因准备而消失。

小文的每一道机关，只能换来一步。

地支割断灯芯，黑暗重新压下。他没有攻击心口，而是切断小文左侧货架，让倒塌木箱封住东门。猎物若有同谋，濒死时会本能逃向对方。

小文偏偏冲向封闭药区。

他扯下挂在梁上的反光铁片。第二盏灯被镜面折向走廊，原本连续的阴影被切成两段。几根藏在木板裂缝里的细根同时收紧，缠住地支脚踝。

只维持了一瞬。

影刃向下，根须齐断。地支却因此慢了半步。

小文钻过货架空隙，肩背的血不断落在地上。他故意不掩盖。地支能读取脚印、停留和动作，却看不见人的想法；越完整的逃跑痕迹，越容易让追猎者相信自己正在逼近真正答案。

“目前只读到一个人的往返影迹。”地支在后方说，“登记室外没有第二组停留痕迹，东门也没有接应者进入。”

“你已经把能看的都看了，还在等我往谁家跑。”小文从货架缝隙钻过，“这不是不信，是你不肯结束任务。”

“相信不属于任务。”地支说，“我只确认还有没有未出现的目标。”

小文抵达东侧装卸巷。暴雨已将排水沟灌到边缘，第三盏油灯藏在雨棚下。他点燃灯，却没有立刻逃。

地支停在巷口。

固定光源将两人的影子投在同一面墙上。小文向左试探，地支的影线便沿墙游动，将他当前脚影缝向身后水管。

小文突然踢倒灯。

火光翻滚，墙面影子变形。缝线落空，钉住了他的裤脚。

地支没有追进雨里：“你提前知道能力限制。”

“医务室的无影灯让你离开墙面，浴室的排水沟让影线停住。”小文握住排水闸绳，“我只看见两次，够我拿命试第三次。”

“两次样本不足以证明完整规则。”地支看着开始晃动的水面，“但你选对了风险。”

这不是赞许，只是执行者对目标难度的重新标记。

小文拉开排水闸。

积蓄在仓库西侧的雨水涌过东巷，翻滚水面把地面暗影切成不断移动的碎片。地支无法沿其中潜行，只能踏上货架残骸。小文则抓住预系绳索跳进排水沟，任水流把自己冲向围墙缺口。

一道影刃从背后掠过，切断半根绳索，也在他腿侧留下伤口。

小文撞进沟壁，几乎昏厥。他仍用木拐护住油布夹层，另一只手割断剩余绳索。失去牵引的绳头被水冲往南侧，自己则从北侧检修口爬出。

地支没有继续追。

他站在雨幕里，低头看着手中一缕细影。刚才近身交错时，他已把缝影结留在账册封皮。只要那本账在稳定光源下投出影子，他便能判断方向与停留时间。

马克给他的命令不是立刻夺回账册。

是找到所有看过账册的人。

“回家吧。”地支说。

小文绕了四条巷子才进入临时藏身处。他脱下湿衣，将账册放到墙角，先检查木拐夹层是否进水。

屋里没有点灯。

只有巷口巡灯每隔数息从破窗扫过，在墙面上推着家具影子缓慢移动。

木桌的影子向左。

木拐的影子向右。

账册封皮下那团影子却始终没有改变方向。

小文正要伸手，墙角忽然响起一声极轻的摩擦。

沙。

几株从砖缝里长出的杂草无风转动，叶面一片接一片朝向账册。最靠近封皮的那片叶子先卷起边缘，绿色沿叶脉迅速退去，像被一滴看不见的墨从根部染黑。

小文的手停在半空。

第二片叶子也黑了。

第三片。

黑色正沿着墙角，朝他站立的位置爬来。

雨幕里，地支最后那句“回家吧”重新贴近耳边。

小文猛地看向窗外。

四条巷子，三次折返，一场足以冲掉血迹的暴雨。

都没有用。

地支根本不需要跟在他身后。

他只是在等这本账册，替小文指出家的方向。
