# 第十章 暴雨仓库

父母的名字落在纸上，像两道已经执行了一半的判决。

小文没有停下来愤怒。

他先看日期，再看人数、车牌暗号和经手签名，最后确认页脚的私人印章。三息之后，他撕下能形成证据链的四页纸，用油布卷紧，塞进老杜木拐的夹层。

账册主体仍留在手里。

这是他准备让追兵夺回去的东西。

门外雨声忽然变得更清楚。

登记室位于仓库北侧夹层，正门向南连接低矮货架区，东墙高窗外就是装卸巷；西侧药品区地势最低，堵住的排水口已经把半座仓库的雨水压在铁闸后。小文原计划从东窗出去，再隔着整片仓库拉开西闸。

这条路线没有真正的安全出口，每一段只负责破坏地支的一种优势。

仓库里的油灯同时熄灭。

黑暗从货架之间合拢。小文没有听见脚步，地支的声音却从四面传来。

“看完了吗？”

第一道影刃贴着登记室门框切下，将木门和退路一同斩断。

小文撞开侧窗，冲向最深处的药品区。那里没有第二个出口，也不可能藏着接应者。地支没有立刻杀他，只用一道道影刃逼迫他改变方向。

“拿给谁？”

“没人。”

“你会去见人。”

“那你跟着。”

小文踢翻第一盏预藏油灯。火焰沿地面铺开，将货架阴影推远半步。地支从墙面暗处退出，轮廓只出现一瞬，影刃已经割开小文肩背。

双方差距没有因准备而消失。

小文的每一道机关，只能换来一步。

地支割断灯芯，黑暗重新压下。他没有攻击心口，而是切断小文左侧货架，让倒塌木箱封住东门。猎物若有同谋，濒死时会本能逃向对方。

小文偏偏冲向封闭药区。

他扯下挂在梁上的反光铁片。第二盏灯被镜面折向走廊，原本连续的阴影被切成两段。几根藏在木板裂缝里的细根同时收紧，缠住地支脚踝。

只维持了一瞬。

影刃向下，根须齐断。地支却因此慢了半步。

小文钻过货架空隙，肩背的血不断落在地上。他故意不掩盖。地支能读取脚印、停留和动作，却看不见人的想法；越完整的逃跑痕迹，越容易让追猎者相信自己正在逼近真正答案。

“一个人。”地支在后方说，“没有接应。”

“你不信？”

“正在确认。”

小文抵达东侧装卸巷。暴雨已将排水沟灌到边缘，第三盏油灯藏在雨棚下。他点燃灯，却没有立刻逃。

地支停在巷口。

固定光源将两人的影子投在同一面墙上。小文向左试探，地支的影线便沿墙游动，将他当前脚影缝向身后水管。

小文突然踢倒灯。

火光翻滚，墙面影子变形。缝线落空，钉住了他的裤脚。

地支没有追进雨里：“你提前知道能力限制。”

“医务室的无影灯，浴室的排水沟。”

“观察准确。”

这不是赞许，只是执行者对目标难度的重新标记。

小文拉开排水闸。

积蓄在仓库西侧的雨水涌过东巷，翻滚水面把地面暗影切成不断移动的碎片。地支无法沿其中潜行，只能踏上货架残骸。小文则抓住预系绳索跳进排水沟，任水流把自己冲向围墙缺口。

一道影刃从背后掠过，切断半根绳索，也在他腿侧留下伤口。

小文撞进沟壁，几乎昏厥。他仍用木拐护住油布夹层，另一只手割断剩余绳索。失去牵引的绳头被水冲往南侧，自己则从北侧检修口爬出。

地支没有继续追。

他站在雨幕里，低头看着手中一缕细影。刚才近身交错时，他已把缝影结留在账册封皮。只要那本账在稳定光源下投出影子，他便能判断方向与停留时间。

马克给他的命令不是立刻夺回账册。

是找到所有看过账册的人。

“回家吧。”地支说。

小文绕了四条巷子才进入临时藏身处。他脱下湿衣，将账册放到墙角，先检查木拐夹层是否进水。

窗外没有风。

墙边几株草却缓缓转向账册封皮。最靠近的一片叶子从边缘开始发黑，像有什么冰冷的东西正沿影子吸走生机。

小文盯着那片叶子，终于明白地支为什么停在雨里。

不是没追上。

是在等他把账册带回家。
