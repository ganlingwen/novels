# 编辑偏好分类

用于 TODO 第 4 项。每条编辑只选一个主要类别，其余可作为次要标签；
类别服务于选题、审核与分层统计，不要求为每类凑相同数量。
已有 `metadata.tags` 保留原样，新批次使用 `metadata.review.category`。
这些类别不等权：`dialogue` 和 `presentation` 是当前真实反馈中最需要优先学习的高频偏好；
`pov` 更多是改善场景进入方式的写作选择，不能凌驾于清楚、自然和有效之上。

| 类别 | 主要检查 | 已读正文中的参照 |
| --- | --- | --- |
| dialogue | 人物是否像活人在具体处境中说话；是否把交流切成四五字碎句，以机械的一问一答推进剧情；台词是否带着人物关系、身体状态、真正关切和未说出口的东西 | 第三章抢救段把“几点？”等碎句合并为带伤势和动作承接的整句；第四章拒绝“你干什么？—回去。—五分钟。—我知道。”式 NPC 对话 |
| presentation | 情绪、动机、关系、病情、选择和伏笔是否由具体动作、对白、感官或物件呈现；旁白是否提前宣布或事后复述已经成立的结论 | 老杜高热由发抖和灼热呼吸呈现；影子断裂和地支顿步已经构成伏笔，不再写“小文记住了” |
| scene | 门、通路、遮挡、站位是否支持实际动作 | 第一章凹位和暗门；第二章检修口与猫的身体位置 |
| pov | 场景、空间和背景是否能随着当事人的目光、听觉、触感或移动自然进入画面，而非由旁白一次性俯拍说明；这是可读性偏好，不要求所有段落严格限定视角 | 第四章随小文起身、转头和撤退人流依次揭示西墙拓扑；第五章由药房声音自然牵引小文视线 |
| character | 行为与对白是否符合人物边界，不新增无依据前史 | 天干报告方位但不能凭魂火给出距离；白川仍继续救治顶撞她的伤员 |
| plot | 编辑是否改变本章目标、选择、不可逆结果或钩子 | 小文为不把猫带回家转向工业街；第五章暂缓登记，章末赶往交换日 |
| continuity | 时间、数字、伤势、道具归属与重复动作是否连贯 | 第二章重复开门、第五章铅笔归属为本轮待审问题 |
| no_change | 被指为问题的内容是否实际成立，应保留原文 | 天干异能报数的历史 false-positive 记录：`real/rejected_pr1_tiangan-ability-false-positive.json` |

## 活人对白与机械问答

`dialogue` 的第一标准不是简短、信息密度或逻辑完整，而是人物在当下是否真的会这样说。
最常见、最严重的失败是把两个人写成剧情接口：每句只有两三个或四五个字，
一人询问参数，另一人提交答案，再轮到下一项信息。句子看似紧凑，实际没有人物、关系和现场。

重点检查：

1. **碎句蹦字。** 同一人物本可一次说完的观察、担忧或请求，被拆成多个独立短行，靠频繁换段伪造节奏。
2. **NPC 式轮询。** 两人严格按“问一句—答一句—再问一句”推进任务，没有迟疑、回避、误解、打断、动作或关系反应。
3. **台词只服务剧情。** 人物说话不是因为自己此刻想知道、害怕、隐瞒或争取什么，只因为作者需要交代下一条信息。
4. **人人同一种理性口吻。** 每个人都完整复述条件、分析原因、给出结论，像说明书或任务系统，而不是不同经历和关系中的人。
5. **省略过度或未卜先知。** 上一句没有说出关键对象，下一句却准确回答；作者删掉承接信息后，追问变成回答无人问过的问题。
6. **没有身体和现场。** 伤势、手中物件、正在进行的工作与人物距离都没有进入交流，台词悬空排列。

真实记录中的典型证据：

| 问题 | 被拒方向 | 已接受方向 | 记录 |
| --- | --- | --- | --- |
| 抢救段碎句 | “几点？”“先别说话。”分成独立短行，白川还提前回答未说出口的“七点” | 小文把父亲治疗说完整；喉咙发紧、低头和拢袖口进入对白承接 | `real/pr100_ch3_rescue-dialogue-merge.json` |
| 紧急场景 NPC 对话 | “你干什么？”“回去。”“五分钟。”“我知道。” | 让小文说出父母赶不到的私人原因，让老杜以木匠身份决定同行 | `real/chapter4_culvert_return_dialogue_pr84.json` |
| 裸碎句与错误合并 | “写五息。”“只用了三息。”“站了五息。”各自悬空；另一版又删掉中间反驳 | 保留问答追问的承接链，用比手、收手、握指等现有动作承载交流 | `real/pr107_ch3_training-record-handoff.json` |
| 熟人像播报日程 | 父母逐项说明“七点”“最后一轮治疗”，或把担忧写成理性路线分析 | 通过多年夫妻的反呛、停顿、起身失败和“他不回来，我还治什么”表达共同焦虑 | `real/pr22_ch2_parents-waiting-dialogue-followup.json` |
| 日常关系被机锋替代 | 搬粮时只用几字短句或俏皮话推进 | 阿慧把空袋塞给小文，同时点出大刘腰上还贴着药 | `real/ch1_pr64_dialogue_pov_20260920.json` |

边界：

- **短句本身不是错误。** 命令、惊吓、疼痛、打断、回避或关系中的默契都可能产生短句；错误是连续用裸短句代替人物交流。
- **也不能一律合并。** 问→答→反驳→追问是活人交流的骨架；为了减少段落而删掉其中一环，会造成未卜先知或莫名回答。
- **动作不是装饰。** 动作应来自伤势、关系、手中物件或正在执行的任务；无动机地看一眼、推单子、转身，只会形成新的机器感。
- **完整句也可能像机器人。** 如果人人都按“条件—分析—结论”完整回答，仍然是说明书对白。
- **对白不必把逻辑说尽。** 熟人共享的信息不复述，真正需要说出口的是当前分歧、请求、遮掩和无法回避的事实。

## 场景随人物进入

`pov` 在这套偏好中主要描述信息如何进入文章，不是要求所有内容都必须证明“人物绝对看得见”。
旁白可以交代场景；但在需要建立空间、关系或异常时，优先让信息跟随当事人的注意和行动出现，
读者会像人在现场一样逐步形成画面，而不是先读一段地图、人物表或机关答案。

优先采用：

1. **由刺激引出注意。** 声音、气味、光线变化、触碰或别人行动先发生，再自然牵引人物看向相关位置。
2. **随移动建立空间。** 人物起身、转头、走近、穿门或试探障碍时，依次交代近处、方向和去路。
3. **按人物关切筛选。** 伤者先注意支撑点，逃生者先找出口，母亲先看儿子衣服上的血迹；不要换成谁都按同一顺序扫描环境。
4. **让背景有现场触发物。** 旧物、伤痕、账单或熟悉路线可以牵出必要背景，少用脱离现场的履历介绍。

真实记录中的典型证据：

| 场景 | 较弱方向 | 已接受方向 | 记录 |
| --- | --- | --- | --- |
| 西墙拓扑 | 一段列出菜地、西墙、涵管、正门和地下入口，像俯视地图 | 小文起身先看西墙，再看南侧正门、近处涵管和身后撤退人流 | `real/pr7_ch4_spatial-reveal-pov.json` |
| 伏击空间 | 旁白一次说明弯柱、检修口和夹道结构 | 小文走到墙边、摸柱脚、侧身试洞后逐步看清夹道 | `real/pr66_chapter2_preferences.json` |
| 药房入场 | 为交代场景机械写“小文朝里看了一眼” | 先听到主管的声音，小文偏头，药房人物与物件随之出现 | `real/pr10_ch5_baichuan-scene-continuity.json` |
| 母亲查看伤势 | 平铺肩伤和腿伤 | 母亲的视线从衣服破口沿血迹落到腿部绷带 | `real/ch3_homecoming_mother_20260920.json` |
| 人物背景 | 旁白直接补述升学和送外卖经历 | 小文碰到腰侧折柄小刀，由眼前物件牵出背景 | `real/pr8_ch1_background-object-trigger.json` |

边界：

- 不要求每段都写“他看见”“她听见”；反复使用这些提示词会形成机械运镜。
- 不要求禁止全知或客观旁白。若旁白能更清楚、简短地完成过渡，可以直接写。
- 只有当段落已经建立贴身观察、遮挡会影响事件理解，或越界信息造成角色未卜先知时，“人物无法感知”才是硬错误。
- `scene` 负责检查空间和动作本身是否成立；`pov` 只检查这些信息以什么顺序、通过什么观察入口交给读者。
- 不能为了贴身视角牺牲必要信息。若人物路径不能让读者建立完整空间，应调整观察顺序或补最短旁白。

## 具体呈现与解释性旁白

这是独立于 `dialogue`、`scene` 和 `pov` 的高频偏好，不能只用“show, don't tell”概括。
检查以下五类问题：

1. **先宣布、后呈现。** 旁白先说病情、情绪或结果，后面的身体状态、动作和现场画面又把同一件事演一遍。
2. **呈现后再解释。** 动作或对白已经让读者看懂，旁白又复述人物没有做什么、为什么这样做、这意味着什么。
3. **抽象总结代替现场反应。** 直接写人物害怕、记住、下定决心或受到冲击，却没有选择、身体反应、感官或手边物件承载它。
4. **替伏笔标注意义。** 异常现象已经出现，又用旁白提醒读者人物注意到了、以后会有用或这一幕很重要。
5. **解释过程代替戏剧动作。** 用战术复盘、参数说明或完整心理计算交代选择，而不是让新信息触发人物当场行动。

真实记录中的典型证据：

| 类型 | 被拒写法 | 已接受方向 | 记录 |
| --- | --- | --- | --- |
| 先宣布病情 | “第二天清晨，老杜开始高热” | 直接进入医务区，以发抖、灼热呼吸和带血指印呈现 | `real/pr28_ch5_morning-medical-transition.json` |
| 标注伏笔 | 影子断裂后再写“小文记住了” | 只保留无影灯、断影和地支顿步，让异常自己成立 | `real/pr10_ch5_shadow-weakness-foreshadow.json` |
| 解释动作意义 | “到底没再拿他的盾开玩笑”“这才朝门口走” | 让陈锋在林夏话未说完时已经行动 | `real/ch2_fangyue_chenfeng_rescue_banter_20260919.json` |
| 解释公开意图 | “让病房里的人都能听见” | 马克转身正对病房，再宣布奖励 | `real/ch3_mark_ward_dialogue_20260919.json` |
| 抽象心理总结 | “这个数字撞了一下小文胸口” | 小文的拇指在裤缝上掐了一下 | `real/pr8_ch1_account-action-externalization.json` |
| 旁白补背景 | 直接补述升学和送外卖经历 | 由腰侧折柄小刀触发相关背景 | `real/pr8_ch1_background-object-trigger.json` |

不能机械地把每句旁白换成动作：

- 动作必须来自人物当下目的、身体状态或环境互动；`把单子推近些` 等无功能动作同样是坏写法。
- 动作已经表达清楚后，不追加解释性尾巴；对白已经表达清楚后，也不再让旁白翻译一遍。
- 必要的问答承接、事实桥和时间信息不能为了“少旁白”被删掉，否则会造成莫名回答、动作跳步或信息缺口。
- 不是所有事实陈述都应隐去。读者无法从现场可靠推出、但理解当前行动所必需的信息，应以最短且有来源的方式交代。

## 本轮采用的采集方式

直接审查前五章现稿，保存同题的原文、A/B 修订和对应事实依据，作者决定采用哪一版或保留原文。
这属于真实编辑互动的采集：AI 生成候选不等于伪造人工偏好。
未审核候选放在 `data/review/`，SFT/DPO eligibility 均为 false。
经作者明确接受的修订可进入 `data/real/`；只有作者明确表达候选间优劣，才启用 DPO。
仅接受修订、未比较其他候选时，只记录 SFT；都不满意或难分优劣时，不推断胜者。
机械一致性修复优先作为 SFT，避免把近乎等价的修法硬标成 DPO。
基于虚构情境批量生成、主要由模型评审的数据仍属于 `data/synthesized/`，保留 synthetic provenance。

## 一致率口径

- 在作者选择前冻结模型对同一 A/B 的偏好；作者审核前不在展示中推荐某一候选。
- 作者选择 A/B 时，可与预先冻结的模型选择作比较；作者选保留原文、都不要、平局或给出新版本时单列统计，不偷偷改成某个 A/B 标签。
- A/B 一致率 = 一致的有效 A/B 判断数 / 作者明确选出 A/B 的判断数；
  同时报告总任务数、有效 A/B 数、平局数、拒绝数和人工改写数，避免只报过滤后的好看比例。
- 修订接受率与 A/B 一致率分别报告。三处全部接受不代表偏好一致率达到 90%。
- 本轮预选来自生成者自评，不是独立双评审；只作流程练习，不用于宣称完成 TODO 第 7 项。
- 100 个有效判断下 90 次一致是 90% 的观测值，仍需报告样本组成与不确定性；
  当前三个任务不具备批量合成验收的代表性。
