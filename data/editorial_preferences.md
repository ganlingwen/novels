# 编辑偏好分类

用于 TODO 第 4 项。每条编辑只选一个主要类别，其余可作为次要标签；
类别服务于选题、审核与分层统计，不要求为每类凑相同数量。
已有 `metadata.tags` 保留原样，新批次使用 `metadata.review.category`。

| 类别 | 主要检查 | 已读正文中的参照 |
| --- | --- | --- |
| dialogue | 对白是否回应人物当前关切；省略是否可理解；是否重复共享信息 | 第二章父母等待段，母亲用“六点四十五”拆穿父亲的自我安慰；第三章“我问的是刚才”追问麻木 |
| scene | 门、通路、遮挡、站位是否支持实际动作 | 第一章凹位和暗门；第二章检修口与猫的身体位置 |
| pov | 信息能否由当前视角人物感知；切换是否明确 | 第一章保温板后只能听见犬猪追逐；第四章突然进入老杜的私人回忆是本轮待审问题 |
| character | 行为与对白是否符合人物边界，不新增无依据前史 | 天干报告方位但不能凭魂火给出距离；白川仍继续救治顶撞她的伤员 |
| plot | 编辑是否改变本章目标、选择、不可逆结果或钩子 | 小文为不把猫带回家转向工业街；第五章暂缓登记，章末赶往交换日 |
| continuity | 时间、数字、伤势、道具归属与重复动作是否连贯 | 第二章重复开门、第五章铅笔归属为本轮待审问题 |
| no_change | 被指为问题的内容是否实际成立，应保留原文 | 天干异能报数的历史 false-positive 记录：`real/rejected_pr1_tiangan-ability-false-positive.json` |

## 本轮采用的采集方式

直接审查前五章现稿，保存同题的原文、A/B 修订和对应事实依据，作者决定采用哪一版或保留原文。
这属于真实编辑互动的采集：AI 生成候选不等于伪造人工偏好。
未审核候选放在 `data/review/`，SFT/DPO eligibility 均为 false。
经作者明确接受的修订可进入 `data/real/`；只有作者明确表达候选间优劣，才启用 DPO。
仅接受修订、未比较其他候选时，只记录 SFT；都不满意或难分优劣时，不推断胜者。
机械一致性修复优先作为 SFT，避免把近乎等价的修法硬标成 DPO。
基于虚构情境批量生成、主要由模型评审的数据仍属于 `data/synthesized/`，保留 synthetic provenance。

## 一致率口径

- 在作者选择前冻结模型对同一 A/B 的偏好；作者审核前不在展示中推荐某一候选。
- 作者选择 A/B 时，可与预先冻结的模型选择作比较；作者选保留原文、都不要、平局或给出新版本时单列统计，不偷偷改成某个 A/B 标签。
- A/B 一致率 = 一致的有效 A/B 判断数 / 作者明确选出 A/B 的判断数；
  同时报告总任务数、有效 A/B 数、平局数、拒绝数和人工改写数，避免只报过滤后的好看比例。
- 修订接受率与 A/B 一致率分别报告。三处全部接受不代表偏好一致率达到 90%。
- 本轮预选来自生成者自评，不是独立双评审；只作流程练习，不用于宣称完成 TODO 第 7 项。
- 100 个有效判断下 90 次一致是 90% 的观测值，仍需报告样本组成与不确定性；
  当前三个任务不具备批量合成验收的代表性。
